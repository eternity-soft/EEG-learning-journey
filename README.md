# EEG Learning Journey 🧠

记录我在 EEG（脑电）和 BCI（脑机接口）学习路上的理解、思考与实践，也希望与同样在探索的朋友交流。

## 这里会记录什么

- **基础知识**：脑电信号、数据预处理、机器学习与深度学习的学习笔记。
- **模型理解**：从数据维度、计算过程和代码实现出发，梳理遇到的模型与方法。
- **论文阅读**：记录论文试图解决的问题、核心思路、实验设置和自己的疑问。
- **实验与实践**：记录数据处理、模型训练、实验配置、结果及遇到的问题。
- **学习日志**：整理阶段性进展、尚未解决的问题和下一步计划。

## 我的学习起点

目前正在探索 EEG / BCI。此前接触过 1D-CNN，并使用 SEED 数据集进行过被试内分类；也在学习 EEGNet 等方法。具体研究方向仍在探索中，后续会结合学习和实践逐步更新。

## 记录原则

- 区分论文中的结论、自己运行得到的结果、个人理解和待验证的问题。
- 实验尽可能记录数据划分、预处理、模型配置和评价方式，方便回顾和复现。
- 笔记是学习过程中的阶段性理解，可能存在错误，欢迎交流与指正。

持续学习，持续记录。
