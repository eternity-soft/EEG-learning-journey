# EEGNet 学习笔记：从脑电输入到三分类

这是我学习 EEGNet 的第一份记录，结合一个使用 PyTorch 实现的 SEED 被试内实验笔记本，梳理每层的数据形状、卷积核和自己的理解。代码与说明是学习记录，后续会随着实验和阅读继续修订。

## 实验范围

- 示例读取同一名被试的一次 Session，输入为 62 个电极、200 Hz 信号。每个 Trial 先按电极使用，将 Trial 整段信号的均值和标准差进行标准化，再切成不重叠的 200 点窗口。剩余不足一窗的数据被舍去。
- 以完整 Trial 划分。前 9 个 Trial 中每类选最后出现的 1 个作为验证，其余 6 个用于训练。Trial 10–15 用于测试，每轮根据验证集交叉熵损失保存模型。
- 每个 Trial 单独使用自身整段统计量，包含该 Trial 内未来时间点的信息，因此这里对应离线、整段已采集的设置。之前查看过的测试 Trial 只能支持探索性对照。这里没有报告新的实验指标。
- `label.mat` 中的 -1、0、1 映射为 0、1、2，分别对应负性、中性和正性。

这些设置描述了单被试、单次记录的实验，结果解释需要以实际运行记录和评估协议为依据。

## 从输入到输出

张量形状按 `(B, C, H, W)` 排列。`B` 是批量大小，`C` 是特征通道数，输入中的 `H=62` 对应电极位置，`W=200` 对应时间采样点。

| 层 | 配置 | 输出形状 |
| --- | --- | --- |
| 输入 | 62 电极，200 点 | `(B,1,62,200)` |
| 时间卷积 + BatchNorm | 8 个 `1×100`，时间方向 padding 50 | `(B,8,62,201)` |
| 深度空间卷积 | `62×1`，groups=8，每组 2 个输出 | `(B,16,1,201)` |
| BatchNorm、ELU、平均池化、Dropout | 池化 `1×4` | `(B,16,1,50)` |
| 深度时间卷积 | `1×16`，groups=16，padding 8 | `(B,16,1,51)` |
| 逐点卷积 | `1×1`，16 个输出通道 | `(B,16,1,51)` |
| BatchNorm、ELU、平均池化、Dropout | 池化 `1×8` | `(B,16,1,6)` |
| Flatten | 每个样本展平 | `(B,96)` |
| Linear | 96 → 3 | `(B,3)` |

第一层长度从 200 变成 201，因为偶数长度核为 100，两侧各填充 50。第二次时间卷积中，50 经核长 16、两侧各填充 8 后变成 51。池化采用向下取整，所以 201 → 50，51 → 6。

## 我的理解

**时间卷积。** `1×100` 表示每次在一个电极位置观察连续 100 个时间点。同一个滤波器的权重在各电极位置共享。按这里 200 Hz 的采样率，100 点对应 0.5 秒。模型学习时间模式，要判断某个滤波器与哪个频段有关，还需要进一步分析其频率响应。

**空间卷积。** `62×1` 在一个时间位置覆盖全部 62 个电极位置，学习加权组合。输入有 8 个时间特征通道，`groups=8` 将它们分组，每组单独产生 2 个空间特征，因此得到 16 个通道。整层权重形状是 `(16,1,62,1)`。

**深度时间卷积和逐点卷积。** 前者用 `groups=16` 分别处理 16 个特征通道的时间序列。后者用 `1×1` 核在每个时间位置融合通道。一个逐点 Filter 有 16 个输入权重，16 个 Filter 形成权重张量 `(16,16,1,1)`。

**分类。** Block2 输出每个样本有 `16×1×6=96` 个特征。展平后由 `Linear(96,3)` 输出 3 个 logits，训练时直接交给交叉熵损失。模型每次优化器更新后调用 `project_weights()`，对空间卷积和分类层权重进行约束。

## 如何运行

打开 [PyTorch Colab 笔记本](../code/SEED_EEGNet_within_subject.ipynb)，在 Google Colab 按顺序执行。准备好按 SEED 数据集要求获得的预处理 EEG 数据和 `label.mat`，按自己的 Google Drive 文件位置修改 `DATA_DIR` 和 `OUTPUT_ROOT`。Python 依赖包括 PyTorch、NumPy、SciPy 和 Matplotlib。代码依赖 `google.colab` 的 Drive 挂载，按 Colab 环境编写。

训练单元按验证损失选权重，最终测试单元单独运行。原始数据、模型权重和实验结果没有随此学习笔记发布。
